# ربات یادگیری واژگان آلمانی (چندکاربره)

هر روز ساعت ۷ صبح به وقت اتاوا، ربات ۴ تم پیشنهادی (با AI و بدون تکرار قبلی‌ها) رو برای **همه‌ی اعضا** توی تلگرام به‌صورت دکمه می‌فرسته. **هرکی از اعضا زودتر جواب بده، همون تم برای همه اعمال می‌شه** و صفت‌ها و فعل‌های آلمانی مرتبط با مثال و معادل انگلیسی برای همه فرستاده می‌شه. اگه کسی «هیچکدام» رو بزنه، ۴ تای جدید پیشنهاد می‌شه. هر کسی که `/start` بزنه، خودکار عضو می‌شه و پیام خوش‌آمد می‌گیره. کاملاً رایگان و بدون نیاز به سرور.

## مرحله ۱: ساخت ربات تلگرام
1. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم دلخواه بده (یوزرنیم باید به `bot` ختم بشه، مثلاً `MyGermanLessonBot`)
3. یه **توکن** بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxx` — نگهش دار
4. لینک عمومی ربات برای اشتراک‌گذاری می‌شه: `https://t.me/یوزرنیمی_که_دادی`

## مرحله ۲: گرفتن Chat ID خودت
1. یه پیام (هر چیزی، مثلاً "سلام") به ربات تازه‌ساخته‌ت بفرست
2. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن مرحله قبل رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. توی خروجی دنبال `"chat":{"id":` بگرد؛ عددش chat id توئه (این فقط برای فعال‌سازی اولیه لازمه)

## مرحله ۳: گرفتن API Key رایگان از Google Gemini
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو و روی **Create API key** بزن
3. نیازی به کارت بانکی نیست
4. کلید رو نگهش دار

## مرحله ۴: ساخت ریپازیتوری در GitHub
1. یه اکانت رایگان در [github.com](https://github.com) بساز (اگه نداری)
2. یه ریپازیتوری جدید بساز (پیشنهاد می‌شه **Private** باشه چون فایل وضعیت ربات شامل chat id اعضاست)
3. فایل `daily_german_bot.py` رو توی ریشه‌ی ریپو آپلود کن
4. یه پوشه به اسم `.github/workflows` بساز و فایل `daily-german-bot.yml` رو داخلش بذار

## مرحله ۵: تنظیم Secrets
توی ریپازیتوری: **Settings → Secrets and variables → Actions → تب Secrets → New repository secret**
سه تا secret **جدا از هم** بساز:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `GEMINI_API_KEY`

## مرحله ۶: فعال کردن مجوز نوشتن
چون ربات باید لیست اعضا و تاریخچه‌ی تم‌ها رو توی فایل `bot_state.json` ذخیره و به ریپو commit کنه:
1. برو **Settings → Actions → General**
2. پایین صفحه، بخش **Workflow permissions**
3. گزینه‌ی **"Read and write permissions"** رو انتخاب کن
4. **Save** بزن

## مرحله ۷: تست
برو تب **Actions**، روی workflow کلیک کن، دکمه‌ی **Run workflow** رو بزن و تیک **force_daily** رو بزن. چند ثانیه بعد باید پیامی با ۴ گزینه‌ی تم توی تلگرامت ببینی.

بعد از این، ربات هر ۵ دقیقه خودش اجرا می‌شه: هم منتظر اعضای جدیده، هم ساعت ۷ صبح اتاوا خودکار چرخه‌ی روزانه رو شروع می‌کنه — دیگه کاری لازم نیست بکنی.

## چطور با بقیه به اشتراک بذارم؟
فقط کافیه لینک ربات (`https://t.me/یوزرنیمی_که_دادی`) رو بفرستی. هرکی روی لینک بزنه و `/start` کنه:
- خودکار به لیست اعضا اضافه می‌شه
- پیام خوش‌آمد می‌گیره
- از فردا صبح، همراه بقیه‌ی اعضا پیام‌های تم و درس روزانه رو دریافت می‌کنه

نیازی نیست هرکسی چیزی نصب کنه یا سکرتی داشته باشه؛ فقط باید ریپازیتوری و سکرت‌ها دست خودت بمونه.

## نکات مهم
- هرکی زودتر (هرکدوم از اعضا) روی یه گزینه بزنه، همون برای همه اعمال می‌شه؛ بقیه فقط پیام «قبلاً یکی جواب داده بود» می‌بینن اگه دیرتر بزنن.
- اگه بعد از فرستادن گزینه‌ها تا **۱۵ دقیقه** هیچ‌کس جواب نده، ربات خودش اولین گزینه رو انتخاب می‌کنه.
- تاریخچه‌ی تم‌های قبلی و لیست اعضا همه توی فایل `bot_state.json` (که خودِ ربات می‌سازه و آپدیت می‌کنه) نگه داشته می‌شه.
- چون هر ۵ دقیقه اجرا می‌شه، دقایق مصرفی GitHub Actions بیشتر از قبله؛ برای ریپوی خصوصی سهمیه‌ی رایگان ماهانه ۲۰۰۰ دقیقه‌ست که برای این حجم کار کاملاً کافیه (هر اجرا چند ثانیه طول می‌کشه).

## تغییر دادن سبک تم‌ها
توی فایل `daily_german_bot.py`، تابع `suggest_new_themes` رو می‌تونی ویرایش کنی.

## تغییر ساعت ارسال
توی `daily_german_bot.py`، خط `now.hour == 7` رو به ساعت دلخواه (به وقت اتاوا) تغییر بده. چون هر ۵ دقیقه چک می‌شه، نیازی به تغییر cron نیست.
