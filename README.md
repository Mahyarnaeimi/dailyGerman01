# ربات یادگیری واژگان آلمانی (چندکاربره)

هر روز ساعت ۷ صبح به وقت اتاوا، ربات ۴ تم پیشنهادی (با AI و بدون تکرار قبلی‌ها) رو برای **همه‌ی اعضا** توی تلگرام به‌صورت دکمه می‌فرسته. **هرکی از اعضا زودتر جواب بده، همون تم برای همه اعمال می‌شه** و صفت‌ها و فعل‌های آلمانی مرتبط با مثال و معادل انگلیسی برای همه فرستاده می‌شه. اگه کسی «هیچکدام» رو بزنه، ۴ تای جدید پیشنهاد می‌شه. هر کسی که `/start` بزنه، خودکار عضو می‌شه و پیام خوش‌آمد می‌گیره. کاملاً رایگان و بدون نیاز به سرور.

## معماری خلاصه
- **ریپازیتوری Public** روی گیت‌هابه — چون گیت‌هاب اکشن برای ریپوهای Public دقایق اجرای نامحدود و رایگان می‌ده (برخلاف Private که سقف ۲۰۰۰ دقیقه در ماه داره).
- وضعیت ربات (لیست اعضا، تاریخچه‌ی تم‌ها و غیره) **توی یه Gist مخفی (Secret) جدا از ریپو** نگه داشته می‌شه، نه توی خود ریپازیتوری. این‌طوری chat id اعضا هیچ‌وقت توی کد Public دیده نمی‌شه.
- اجرا هر ۵ دقیقه توسط سرویس بیرونی رایگان **cron-job.org** انجام می‌شه که endpoint دیسپچ ورک‌فلو گیت‌هاب رو صدا می‌زنه. کرون داخلی خودِ گیت‌هاب (`schedule:`) فقط به‌عنوان یه بک‌آپ ساعتی نگه داشته شده، چون برای بازه‌های کوتاه (هر ۵ دقیقه) قابل‌اعتماد نیست و ممکنه ساعت‌ها دیر اجرا بشه یا اصلاً skip بشه.

## مرحله ۱: ساخت ربات تلگرام
1. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم دلخواه بده (یوزرنیم باید به `bot` ختم بشه، مثلاً `MyGermanLessonBot`)
3. یه **توکن** بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxx` — نگهش دار
4. لینک عمومی ربات برای اشتراک‌گذاری می‌شه: `https://t.me/یوزرنیمی_که_دادی`
5. (اختیاری ولی پیشنهادی) توی همون چت BotFather دستور `/setcommands` رو بزن، ربات رو انتخاب کن و فقط یه خط بفرست:
   `start - شروع و عضویت در ربات یادگیری واژگان آلمانی`
   این‌طوری منوی دستورات ربات توی تلگرام تمیز می‌مونه و فقط `/start` نشون داده می‌شه.

## مرحله ۲: گرفتن Chat ID خودت
1. یه پیام (هر چیزی، مثلاً "سلام") به ربات تازه‌ساخته‌ت بفرست
2. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن مرحله قبل رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. توی خروجی دنبال `"chat":{"id":` بگرد؛ عددش chat id توئه (این فقط برای فعال‌سازی اولیه لازمه)

## مرحله ۳: گرفتن API Key رایگان از Google Gemini
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو و روی **Create API key** بزن
3. نیازی به کارت بانکی نیست
4. کلید رو نگهش دار

## مرحله ۴: ساخت ریپازیتوری در GitHub
1. یه اکانت رایگان در [github.com](https://github.com) بساز (اگه نداری)
2. یه ریپازیتوری جدید بساز و حتماً **Public** انتخابش کن (چون state دیگه توی ریپو ذخیره نمی‌شه، پابلیک بودنش مشکلی برای حریم خصوصی نداره و اکشن‌هاش هم رایگان و نامحدود می‌مونه)
3. فایل `daily_german_bot.py` رو توی ریشه‌ی ریپو آپلود کن
4. یه پوشه به اسم `.github/workflows` بساز و فایل `main.yml` رو داخلش بذار

## مرحله ۵: ساخت Gist مخفی برای ذخیره‌ی وضعیت
1. برو به [gist.github.com](https://gist.github.com)
2. یه Gist جدید بساز: اسم فایل `bot_state.json`، محتوای اولیه هر چیز موقتی (مثلاً `not initialized yet` — ربات خودش دفعه‌ی اول با مقدار پیش‌فرض جایگزینش می‌کنه)
3. حتماً دکمه‌ی **Create secret gist** رو بزن (نه Public gist)
4. از آدرس Gist، شناسه (ID) بعد از یوزرنیمت رو یادداشت کن؛ مثلاً در `gist.github.com/username/abc123...` بخش `abc123...` همون **GIST_ID** هست

## مرحله ۶: ساخت توکن دسترسی برای Gist
1. برو به [github.com/settings/tokens](https://github.com/settings/tokens) و یه **Personal Access Token** بساز (Classic هم کافیه)
2. فقط اسکوپ **gist** رو تیک بزن (نیازی به هیچ دسترسی دیگه‌ای نیست)
3. توکن ساخته‌شده رو نگه دار — این می‌شه **GIST_TOKEN**

## مرحله ۷: تنظیم Secrets مخزن
توی ریپازیتوری: **Settings → Secrets and variables → Actions → تب Secrets → New repository secret**
این ۵ تا secret **جدا از هم** بساز:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `GEMINI_API_KEY`
- `GIST_TOKEN` (از مرحله‌ی ۶)
- `GIST_ID` (از مرحله‌ی ۵)
- `GEMINI_API_KEY`
- `GIST_TOKEN` (از مرحله‌ی ۶)
- `GIST_ID` (از مرحله‌ی ۵)

## مرحله ۸: تنظیم اجرای هر ۵ دقیقه با cron-job.org
1. توی [cron-job.org](https://cron-job.org) یه اکانت رایگان بساز
2. یه Cronjob جدید بساز با این تنظیمات:
   - **URL**: `https://api.github.com/repos/<یوزرنیم>/<ریپو>/actions/workflows/main.yml/dispatches`
      - **Method**: POST
         - **Headers**:
              - `Accept: application/vnd.github+json`
                   - `Authorization: Bearer <یه Personal Access Token دیگه با اسکوپ actions:write یا repo>`
                        - `Content-Type: application/json`
                           - **Request body**: `{"ref":"main"}`
                              - **Schedule**: هر ۵ دقیقه (یا هر بازه‌ی دلخواه)
                              3. مطمئن شو کرون‌جاب **Enable** هست — cron-job.org اگه یه کرون‌جاب چندبار پشت‌سرهم فیل بشه، خودش به‌صورت خودکار غیرفعالش می‌کنه؛ گاه‌گداری سر بزن و چک کن که هنوز فعاله
