# ربات یادگیری واژگان آلمانی روزانه

هر روز ساعت ۷ صبح به وقت اتاوا، ربات ۴ تم پیشنهادی (که با AI و بدون تکرار قبلی‌ها ساخته می‌شه) رو توی تلگرام به‌صورت دکمه می‌فرسته. هرکدوم رو انتخاب کنی، صفت‌ها و فعل‌های آلمانی مرتبط با مثال و معادل انگلیسی برات میاد. اگه هیچ‌کدوم رو نخوای، دکمه‌ی «هیچکدام» ۴ تای جدید پیشنهاد می‌ده. کاملاً رایگان و بدون نیاز به سرور.

## مرحله ۱: ساخت ربات تلگرام
1. توی تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بفرست و اسم و یوزرنیم دلخواه بده
3. یه **توکن** بهت می‌ده شبیه این: `123456789:AAExxxxxxxxxxxxxxxxxxxx` — نگهش دار

## مرحله ۲: گرفتن Chat ID خودت
1. یه پیام (هر چیزی، مثلاً "سلام") به ربات تازه‌ساخته‌ت بفرست
2. توی مرورگر این آدرس رو باز کن (به‌جای `<TOKEN>` توکن مرحله قبل رو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. توی خروجی دنبال `"chat":{"id":` بگرد؛ عددش chat id توئه

## مرحله ۳: گرفتن API Key رایگان از Google Gemini
1. برو به [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. با اکانت گوگلت وارد شو و روی **Create API key** بزن
3. نیازی به کارت بانکی نیست؛ سهمیه‌ی رایگان روزانه برای این کاربرد کاملاً کافیه
4. کلید رو نگهش دار

## مرحله ۴: ساخت ریپازیتوری در GitHub
1. یه اکانت رایگان در [github.com](https://github.com) بساز (اگه نداری)
2. یه ریپازیتوری جدید (خصوصی یا عمومی، فرقی نداره) بساز
3. فایل `daily_german_bot.py` رو توی ریشه‌ی ریپو آپلود کن
4. یه پوشه به اسم `.github/workflows` بساز و فایل `daily-german-bot.yml` رو داخلش بذار

## مرحله ۵: تنظیم Secrets
توی ریپازیتوری: **Settings → Secrets and variables → Actions → تب Secrets → New repository secret**
سه تا secret **جدا از هم** (هر بار فقط یه Name و یه Value، بدون قاطی کردن) با این اسم‌ها بساز:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `GEMINI_API_KEY`

## مرحله ۶: فعال کردن مجوز نوشتن (برای ذخیره‌ی تاریخچه‌ی تم‌ها)
چون ربات باید تم‌های استفاده‌شده رو توی فایل `themes_history.json` ذخیره و به ریپو commit کنه، باید مجوز نوشتن (write) رو فعال کنی:
1. برو **Settings → Actions → General**
2. پایین صفحه، بخش **Workflow permissions**
3. گزینه‌ی **"Read and write permissions"** رو انتخاب کن
4. **Save** بزن

## مرحله ۷: تست
برو تب **Actions**، روی workflow کلیک کن، دکمه‌ی **Run workflow** رو بزن و تیک **force** رو بزن (تا بدون منتظر موندن برای ساعت ۷ صبح، همین الان اجرا بشه). چند ثانیه بعد باید پیامی با ۴ گزینه‌ی تم توی تلگرامت ببینی — روی یکی بزن یا «هیچکدام» رو انتخاب کن.

بعد از این، هر روز ساعت ۷ صبح به وقت اتاوا خودکار اجرا می‌شه — دیگه کاری لازم نیست بکنی.

## نکات مهم درباره‌ی نسخه‌ی تعاملی
- ربات بعد از فرستادن گزینه‌ها، حداکثر **۱۵ دقیقه** منتظر جواب تو می‌مونه. اگه جواب ندی، خودش اولین گزینه رو انتخاب می‌کنه تا روز از دست نره.
- تاریخچه‌ی تم‌های قبلی توی فایل `themes_history.json` (که خودِ ربات می‌سازه) نگه داشته می‌شه، پس تکراری پیشنهاد داده نمی‌شه.
- زمان‌بندی cron دوبار در روز (ساعت ۱۱ و ۱۲ UTC) فعال می‌شه چون اتاوا بین تابستون و زمستون یک ساعت جابه‌جا می‌شه؛ خودِ اسکریپت چک می‌کنه کدوم لحظه واقعاً ساعت ۷ صبح اتاواست و فقط همون‌موقع کار رو ادامه می‌ده (اون یکی بدون کاری بی‌سروصدا تموم می‌شه).

## تغییر دادن سبک تم‌ها
توی فایل `daily_german_bot.py`، تابع `suggest_new_themes` رو می‌تونی ویرایش کنی تا سبک/حال‌وهوای تم‌های پیشنهادی رو تغییر بدی (مثلاً محدودش کنی به موضوعات خاص).

## تغییر ساعت ارسال
اگه می‌خوای ساعت دیگه‌ای (نه ۷ صبح اتاوا) باشه:
1. توی `daily_german_bot.py`، خط `now_ottawa.hour == 7` رو به ساعت دلخواه تغییر بده
2. توی فایل yml، دو خط cron رو با ساعت UTC معادل جدید (هم برای EDT هم EST) عوض کن
